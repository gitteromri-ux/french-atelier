# French Atelier recovered brand image library

This folder contains 20 existing French Atelier images copied at original resolution, without resizing or recompression. The source manifest records exact dimensions, byte counts, repository paths, and direct source URLs for every image.

## Curated selection

- **Email/culture:** 12 images cover Colmar, rail travel, food symbols, Brittany, fashion, gastronomy, seasonal dessert, Lyon architecture, coffee, cinema, music, and café reflection.
- **Website/Capsules:** Eight images cover Versailles, Paris rooftops, a French salon, a grand staircase, Impressionism, Louis-era décor, a Chanel-style atelier, and a book still life.
- **Excluded:** The realistic Julien portrait is intentionally absent to avoid confusion with a real tutor. Images containing prominent overlaid marketing text were also excluded.
- **Visual review:** Every original was successfully decoded and its dimensions checked. `review-contact-sheet.jpg` was viewed to confirm subjects and identify filename mismatches; it is the only resized review asset.
- **Naming correction:** The original gallery `email10_cinema.jpg` depicts a coffee counter, while `email9_coffee.jpg` depicts a cinema audience. Local descriptive names correct this without altering the original binaries.
- **Provenance caveat:** Existing repository presence does not independently verify licensing, photographic authenticity, or the identity of depicted people. Some source assets are generated/composited illustrations.
