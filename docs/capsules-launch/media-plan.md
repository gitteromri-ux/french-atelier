# French Atelier — Culture Capsules: 10-Day Meta Launch Plan

**Period:** Thu 15 Oct – Sat 24 Oct 2026 (10 days) · **Budget:** $500/day → **$5,000 total** · **Objective:** Sales / Purchase (pixel, 7-day click / 1-day view, lowest cost)
**Landing page:** https://fa-capsules-d.pplx.app/capsules.html (new pricing design: branch `staging-capsules-light`)
**Offer:** 1 capsule $297 (3 × $99) · 2 capsules $534 (3 × $178, $89/capsule) · All 3 $567 (3 × $189, $63/capsule, best seller) · code **CAPSULE20** = extra 20% off any package.

This is a **signal test, not a scale phase**. ROAS is not expected to be positive by Day 10. The goal is to exit learning fast, find the 2–3 ads and the audience that convert, and land **5–10 purchases by Day 10** with a readable trend, then scale what works.

## 5. Decision gates

| Gate | When | Green (keep / scale) | Yellow (fix) | Red (kill / swap) |
|---|---|---|---|---|
| **G1 — Delivery** | Day 3 (17 Oct) | CPM ≤ $32, CPC ≤ $2.50, LPV rate ≥ 70% | CPC $2.50–3.50 → swap thumbnail / hook on worst 2 ads | CPC > $3.50 on an ad → pause it; ad set with 0 checkouts → replace 2 ads |
| **G2 — Intent** | Day 5 (19 Oct) | ≥ 6 checkouts started cumulative, ≥ 1 purchase | 3–5 checkouts → move $50/day from worst set to best set | < 3 checkouts → re-check pixel + page, replace creatives in that set |
| **G3 — Trend** | Day 7 (21 Oct) | ≥ 4 purchases cumulative, CPA trend down | 2–3 purchases → hold budgets, kill bottom 40% of ads | 0–1 purchases → stop prospecting set with 0 sales, keep RT + best set |
| **G4 — Verdict** | Day 10 (24 Oct) | ≥ 5 purchases, LPV→purchase ≥ 0.5%, CPA ≤ $650 → scale | 3–4 purchases → extend 4 days at same spend, new creatives only | < 3 purchases → stop, fix offer / page, do not add budget |

Ad-level rules (checked daily from Day 3): kill any ad with ≥ $120 spend and 0 checkouts; kill any ad with CTR < 0.6% after 8,000 impressions; never edit a winning ad (duplicate instead).

**What a positive trend looks like by Day 10:** CPC falling week-over-week, LPV→checkout ≥ 1%, checkout→purchase ≥ 60%, 5–10 purchases, at least 2 ads with CPA under $500, retargeting CPA under $300.

**Week 3–4 if green:** raise the best prospecting set +20% every 48 h (never more), duplicate the top 3 ads into a new LAL 3–5% set at $150/day, keep retargeting at 20% of total spend. Target: 25–40 purchases on $10k, CPA ≤ $350, ROAS ≥ 1.2 gross.

## 6. Phase 2 (days 11–14)

**Green:** continue at $500–600/day with the same 3 sets, add 4 new creatives (2 UGC, 2 reels) built from the winning hooks, and raise the top set by 20%. **Red:** pause prospecting, keep retargeting at $100/day for 4 days to close the warm pool, and fix the page or the offer before any new money. The plan never exceeds $5,000 in the first 10 days.
